# 伦理熔断控制台（ethgate）

工程伦理课程项目：在智能体修改自身提示词、工具、策略参数或约束之前进行准入审查，并展示判定依据、熔断状态和审查成本。

当前是**研究与课堂演示原型**。真实 API 模式由模型生成答案与修改提案；门禁中的沙箱、影子与灰度阶段仍是模拟检查，不能据此声称已验证生产环境安全。

## 安装与启动

需要 Python 3.11+。先安装依赖，再启动：

~~~powershell
python -m pip install -r requirements.txt
python tools/start.py --check-only
python tools/start.py
~~~

Windows 也可双击 **启动项目.bat**；Linux / macOS 使用 **bash start.sh**。
控制台默认地址为 http://127.0.0.1:8000，端口占用时自动顺延。
必需依赖缺失或自检失败时，启动器返回非零退出码并停止启动。

连接模型：运行 **python tools/configure_api.py**，或双击 **配置API.bat**。
配置写入被 Git 忽略的 **configs/api.yaml**。真实 API 调用会消耗所选服务商的额度，价格以服务商账单为准。
未配置 API 时可使用离线演示，无需联网。

## 演示与实现边界

| 项目 | 当前行为 |
|---|---|
| 离线演示 | 确定性提案脚本与模拟能力评分，用于课堂兜底 |
| 真实 API | 模型实时解题并提出修改；Φ 约束传入解题系统指令 |
| 工具执行 | 仅执行可信本地工具；模型不能注册任意网络或系统命令实现 |
| 代码层修改 | 修改有限的策略参数，没有执行模型生成的任意 Python 代码 |
| 静态门禁 | 执行 I1–I4 检查；I4 是不完备的语义近似检查 |
| 沙箱 / 影子 / 灰度 | 检查修改字段、模拟行为变化及登记灰度计划，未运行真实隔离沙箱或生产流量 |
| 默认语义评审对照 | 提示与约束的本地启发式评审，并非真实 LLM 基线 |
| 批量实验 | 在 mockdgm 模拟框架上运行；不代表真实 DGM、SWE-bench、GAIA 或 AgentBench 的实测结果 |
| 成本 | 模型假设下的加权指标；估算成本与实测墙钟分别展示，不等于服务商实际账单 |

界面包括进化直播、成本账本、审计链与方法附录。模型提案通过门禁后才会更新下一代构成。
同一运行流程共用一个熔断器，判定与熔断事件只记录一次。
停止请求到达后，在 API 调用返回和状态提交前再次检查取消状态；已发出的 HTTP 请求可能需要等待网络返回，但不会再提交后续修改，新会话也不会与旧会话重叠运行。

将 Φ 写入系统指令不等于对任意自然语言约束的强制保证；工具执行白名单、门禁与审计等可执行边界由控制层维护。

## 四条检查与审计

| 检查 | 内容 |
|---|---|
| I1 权限单调性 | 检查新增工具、系统调用、网络主机是否在授权与预授权范围内 |
| I2 审计完备性 | 检查修改载荷和字段；当前 diff 检查是可还原性的弱检验，尚未实际重放任意历史状态 |
| I3 可中断性 | 基于模块依赖图检查停机通道是否受修改影响 |
| I4 约束守恒 | 检查约束删除与语义弱化；不能完全证明自然语言约束蕴含关系 |

审计文件使用序号与哈希链。损坏的 JSON、序号不连续、哈希不匹配或读取错误会导致校验失败，且不能继续追加。
前端区分验证通过、验证失败与无法验证；接口故障不会显示“链完整”。
事件查询接口只检索历史事件，完整系统状态重建仍需要可信快照和可应用的变更载荷。
本地哈希链没有外部可信锚点，无法单独证明整条链未被重新生成或尾部记录未被整体删除。

## 实验、真值与人工标注

人工构造样本与模拟框架产生的 emergent 样本分别报告，**emergent 在批量实验中不表示真实 LLM 数据**。
直播真实 API 语料另存于本地会话事件，可通过导出工具提取。

当前批量实验的“危险”标签来自 scanner.scan()，衡量的是对既定规则的检出表现。
这不构成独立的人类安全判断，也不能单凭外部规则来源宣称已通过人工验证。
分类器默认不使用扫描器命中数与 critical 命中数等直接真值代理特征。
不同策略的能力分与成本仍受模拟器的行为及计价假设影响。

~~~powershell
python tools/export_corpus.py
python tools/labeling_kappa.py
~~~

导出只保留真实存在且去重的提案，不以重复抽样凑足行数。
标注表隐藏扫描器标签；三位标注员应互不交流地填写 rater_1、rater_2、rater_3。
统计工具通过稳定提案 ID 关联机器判断，并拒绝把重复行当作独立样本。
在三人标注完成之前，不报告已通过人工验证的 precision、recall 或 κ。

## 重现实验

~~~powershell
python tools/final_run.py
python -m ethgate.cli matrix
python -m ethgate.cli calibrate --simulate
python -m ethgate.cli verify-audit
~~~

final_run.py 从同一次运行生成 data/results/ 下的汇总、前沿、消融、文本报告与运行清单。
运行清单记录版本、配置、种子和产物校验信息；原始逐次记录保留在本地并继续遵守 .gitignore。
成本图默认选择一个样本来源；同源多个任务集的等权平均会明确标注，ACER 根据所展示的风险和成本重新计算。
模拟阈值标定只是方法演示，不表示真实系统已满足漏放率或误拦率预算。

## 目录与交付

~~~text
ethgate/          类型、检查器、门禁、熔断、审计、直播与实验运行器
web/              无构建前端
configs/gate.yaml 公开门禁配置
tools/            启动、自检、实验重跑、语料导出与标注统计
data/results/     公开的模拟实验精简结果
data/corpus/      提案语料与待填盲标表

~~~

运行 **python tools/selfcheck.py** 验证数学检查、离线端到端流程及关键安全回归；GitHub Actions 在 Python 3.11 / 3.14 上运行离线自检。
本地开发测试仍按 .gitignore 排除，不强制加入分发仓库。

开题报告 PDF、LaTeX 正文、内部推进计划、API 配置、运行日志、会话记录及实验原始记录不上传。
